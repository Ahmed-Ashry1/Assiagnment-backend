# Students and Doctors API

A Node.js RESTful API to manage students and doctors using MongoDB Atlas and Mongoose.

## Features

- Add a hardcoded student
- Add a student from request body
- Add a doctor from query parameters
- Get all students
- Get all doctors
- Delete a student by ID
- Update a doctor's name using query parameters
- Get all students and doctors

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
